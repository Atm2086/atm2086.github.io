# JavaType实验设计

调用形式是：
```
JavaTypeCacheV2 Cache;  // 放在多次查询之外

CachedJavaTypeQueryInfo Info;
JavaTypeCacheV2Diagnostics D;

JavaType T = getCachedJavaTypeV2(V, DT, Context, Oracle, Cache, Info, &D);
```


## 指标

一些综合指标：

- BaseHits/BaseMisses：进入Base求解器时候，目标值是否已经算过

- InputHits/InputMisses：根没有命中，它依赖的子问题是否复用

- PriorQueryHits/CurrentQueryHits：跨查询的复用；查询内memo复用

- EntriesAdded：一次顶层查询后的完成条目净增加量

- 失效指标：
    - ValueVisited：沿 users 图访问了多少个不同值
    - UseVisited：遍历了多少条 use
    - BaseRemoved：实际删除多少条 Base 结果
    - FullClear：是否因为无法分类或遍历超限，回退到整表清空

| 指标 | 数值 | 原因 |
|---|---:|---|
| `NodesEvaluated` | 3 | 新求值的节点是 `p、q、a` |
| `InputEdgesVisited` | 4 | 图中四条依赖边都被访问 |
| `OpenNodeEdges` | 1 | 处理 `q → p` 时，`p` 尚未完成 |
| `CyclicSCCs` | 1 | 实际求解 `{p, q}` 这个分量 |
| `RefinementSteps` | 2 | 分量内两个节点各处理一次 |

这几个指标，减少就代表缓存起作用了，都是SCC算法里的。


## cold & warm

cold：每次查询前清空指定缓存，测量不复用之前结果时候需要多少工作

warm：查询之间保留缓存，测量能省多少。
